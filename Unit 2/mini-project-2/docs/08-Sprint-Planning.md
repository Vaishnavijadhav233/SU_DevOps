# 8. Sprint Planning

The following is a sample three-sprint plan based on the assignment. Update dates and scope to match the actual class schedule and team capacity.

## Sprint 1 — Project setup and authentication
**Sprint goal:** Establish the project structure and plan the authentication workflow.

**Planned work**
- Initialize the repository and documentation.
- Define the basic application structure.
- Plan and, if implementing software, develop login and logout.
- Define access roles.
- Test the authentication flow.

**Candidate stories:** US-01, US-02, and the initial part of US-15.  
**Expected deliverable:** Project setup and an agreed authentication design or working authentication increment, depending on the implementation scope.

## Sprint 2 — Student management
**Sprint goal:** Enable authorized users to maintain student records.

**Planned work**
- Add student records.
- Search student records.
- Update student details.
- Define safe handling of record deletion.
- Test validation and record operations.

**Candidate stories:** US-03, US-04, US-05, US-06.  
**Expected deliverable:** Student management design or working increment with tested acceptance criteria.

## Sprint 3 — Course and attendance management
**Sprint goal:** Organize courses and record attendance.

**Planned work**
- Add courses.
- Assign students to courses.
- Record attendance by course and date.
- View attendance records.
- Prepare an attendance report.

**Candidate stories:** US-07, US-08, US-09, US-10.  
**Expected deliverable:** Course and attendance design or working increment with tested acceptance criteria.

## Sprint planning checklist
- Confirm the Sprint Goal.
- Select prioritized backlog items.
- Check dependencies and team capacity.
- Agree on the acceptance criteria.
- Break selected stories into tasks.
- Update the Sprint Backlog and Scrum Board.
