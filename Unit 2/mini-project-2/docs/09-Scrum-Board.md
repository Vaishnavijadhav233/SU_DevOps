**Important:** The entries under Completed refer only to repository setup and planning documents if those tasks have actually been completed. Do not claim application features are complete unless they have been implemented and tested.

## Board policies
- **Backlog:** identified but not yet selected.
- **To Do:** selected for work but not started.
- **In Progress:** currently being worked on.
- **Testing:** implementation is awaiting or undergoing verification.
- **Completed:** acceptance criteria have passed and the team has accepted the item.

Update this board during each Sprint and keep it consistent with the real project status.
