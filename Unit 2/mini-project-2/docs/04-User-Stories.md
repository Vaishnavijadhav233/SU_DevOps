# 4. User Story Repository

User stories use the format: **As a [user], I want [capability], so that [benefit].**

| ID | Epic | User story | Priority | Story points |
|---|---|---|---|---:|
| US-01 | Authentication | As an authorized user, I want to log in so that I can access permitted features. | High | 5 |
| US-02 | Authentication | As a user, I want to log out so that my session is closed when I finish. | High | 2 |
| US-03 | Student Management | As an administrator, I want to add a student so that the student's details are recorded. | High | 3 |
| US-04 | Student Management | As an administrator, I want to search for a student so that I can find a record quickly. | High | 2 |
| US-05 | Student Management | As an administrator, I want to update student details so that records remain current. | High | 3 |
| US-06 | Student Management | As an administrator, I want to delete an eligible student record so that obsolete records can be handled according to policy. | Medium | 5 |
| US-07 | Course Management | As an administrator, I want to add a course so that course information is available. | Medium | 3 |
| US-08 | Course Management | As an administrator, I want to assign students to courses so that enrollments are recorded. | Medium | 5 |
| US-09 | Attendance | As a faculty member, I want to record attendance for a course and date so that attendance records remain accurate. | High | 5 |
| US-10 | Attendance | As a faculty member, I want to view attendance records so that I can check attendance history. | High | 3 |
| US-11 | Marks and Performance | As a faculty member, I want to enter marks so that assessment results are recorded. | Medium | 5 |
| US-12 | Marks and Performance | As a student or authorized faculty member, I want to view a result sheet so that academic performance can be reviewed. | Medium | 5 |
| US-13 | Reporting | As an administrator, I want to generate student and course reports so that I can review academic information. | Medium | 5 |
| US-14 | Notifications | As a student, I want to receive examination and result notifications so that I know about important academic events. | Low | 5 |
| US-15 | Security | As an administrator, I want access permissions based on roles so that sensitive information is protected. | High | 8 |

Story points are initial planning estimates and should be reviewed by the team during planning.
