# Sprint Burndown Chart

A burndown chart compares remaining work with the time left in a Sprint.

## How to prepare it
1. Select the Sprint and list the committed stories.
2. Record the total estimated work at the start of the Sprint.
3. At the end of each workday, calculate the remaining work using the team's chosen unit (for example, story points).
4. Plot the remaining work by day and compare it with the ideal burndown.
5. Explain major differences and update the next Sprint plan.

## Important
The CSV in this folder is a **sample illustration only**, not actual project progress. Replace it with your team's real Sprint data before submission.
