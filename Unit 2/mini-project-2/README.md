# Mini Project 2 — Agile Project Planning
## Student Record and Academic Management Platform

This repository contains the Unit 2 Agile mini-project deliverables for planning a Student Record and Academic Management Platform.

## Project overview
The proposed platform is a secure, user-friendly web application to help an educational institution manage student records, courses, attendance, academic performance, and reports.

## Repository structure
- `docs/` — Product vision, Scrum roles, epics, user stories, acceptance criteria, backlog, estimates, sprint plan, ceremonies, framework comparison, and roadmap.
- `reports/` — Overall planning report, sprint review template, and retrospective report.
- `boards/` — Sample Scrum board.
- `charts/` — Sample burndown data and chart notes.

## Agile approach
The project uses Scrum as the primary planning framework, with three sample sprints:
1. Project setup and authentication
2. Student management
3. Course and attendance management

These are planning artifacts for the academic assignment. Sprint outcomes should be updated to reflect the work actually completed by the team.

## How to use
Open the Markdown files directly on GitHub. Replace team-member placeholders with your actual team details, and update progress, dates, and sprint results based on your work.
